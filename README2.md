## Netflix Dataset Preprocessing and PCA Analysis

This assignment focuses on data preprocessing techniques using the Netflix Titles dataset.

The following tasks were completed:

- Identified data quality issues
- Handled missing values
- Detected and removed outliers using the IQR method
- Applied normalization techniques:
  - Min-Max Normalization
  - Z-score Standardization
- Applied PCA (Principal Component Analysis)
- Interpreted explained variance results
